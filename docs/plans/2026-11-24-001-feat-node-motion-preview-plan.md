# 节点动效配置与预览

首版让用户在右侧属性面板给选中节点设置持续自转或往返移动，显式启动预览，并在退出预览后继续编辑。用户可以用一台风扇和一个滑台走完配置、播放、停止、撤销与重新打开项目的完整流程。

## 操作流程

1. 从画布或层级树选中单个模型节点，或能独立变换的 GLB 子节点。右侧「对象」组提供与「变换」「材质」同级的「动效」页签。
2. 在「动效」页签添加持续自转或往返移动。每个节点首版可保存一项动效，支持修改、切换类型和移除。新增和切换类型使用该类型的默认参数，字段沿用 Inspector 的提交流程，每次有效提交可撤销。
3. 点击「预览」播放当前节点已提交的配置。面板显示预览状态和「停止」，预览期间锁定动效参数与目标节点的变换编辑，仍可移动视角和切换选中对象。
4. 点击「停止」、切换选中节点、离开动效页签或重新投影 Snapshot 时结束预览。继续编辑前，目标回到基础姿态。重新预览从起点开始。

| 类型 | 字段和默认值 | 播放行为 |
| --- | --- | --- |
| 持续自转 | 局部轴 X / Y / Z，默认 Y。带方向的转速，默认 +90°/秒 | 绕节点自身轴心匀速旋转，正负值控制方向。 |
| 往返移动 | 父级轴 X / Y / Z，默认 X。带方向的位移，默认 +1 场景单位。单程时长，默认 2 秒 | 从基础位置移到偏移终点，再平滑返回并循环。单程 2 秒对应 4 秒一个周期，首版使用固定缓入缓出。 |

面板在目标尚未加载或 GLB 子节点无法解析时解释为何暂时无法预览。数值字段拒绝非有限值，转速与位移要求非零，单程时长要求大于零。

## 实现顺序

1. **Core 配置和命令。** 在支持的 SceneNode 上定义可选、按类型区分的 JSON 配置，用稳定的节点 ID 定位编辑目标。通过现有 command/history 校验并提交配置，纳入 Snapshot 的版本升级、序列化与恢复。旧项目加载时对应节点的动效为空。删除节点时配置随节点移除，既有节点复制操作携带配置副本。 [Snapshot 类型](../../packages/core/src/snapshot/types.ts) · [命令分发](../../packages/core/src/commands/dispatcher.ts)
2. **Core 视口预览。** 在现有 runtime 和帧调度中只播放一个目标。开始时用 runtime target map 找到目标并读取投影完成后的基础变换。GLB 子节点有变换覆盖时以覆盖后的姿态为基准，否则采用模型的原始局部姿态。每帧根据从起点算出的经过时间叠加旋转或位移。停止时复位并恢复按需绘制。退出时清理运行状态，Snapshot 重新投影前先结束旧预览。 [运行时](../../packages/core/src/runtime/editor-runtime.ts) · [场景投影](../../packages/core/src/runtime/scene-projector.ts)
3. **React 和 Vue 面板。** Core 提供同一套 Inspector 字段、适用性与校验。先串通 React 默认工作台，再对齐 Vue 操作和中英文文案。播放按钮操作 runtime，参数提交走编辑命令。确认窄侧栏里的字段单位和播放状态可见。 [React Inspector](../../packages/react/src/components/InspectorView.tsx) · [Vue Inspector](../../packages/vue/src/components/InspectorView.vue) · [Inspector 样式发布边界](../adr/0001-react-inspector-ui-style-boundary.md)
4. **集成验收。** 通过现有 Editor 命令、runtime 帧调度和两端工作台入口验证配置与播放。用仓库的包级 Vitest、浏览器测试配置和工作区类型检查验证交付。

## 验收条件

- 选中风扇的 GLB 叶片，以局部 Y 轴和 +90°/秒预览。叶片一秒转过 90°、四秒转一圈，外壳保持原位。停止后恢复叶片的原始局部姿态。
- 选中滑台设为父级 X 轴、+1 场景单位、单程 2 秒。预览第 2 秒到达终点，第 4 秒返回起点。位移以父级坐标轴为准，在父级转过方向的场景中也能验证。
- 播放和停止前后的 Snapshot、历史栈与导出数据一致。预览期间导出的项目仍保存基础姿态和已提交配置。撤销、重做、保存并重新加载后，配置能按预期恢复，并可从起点再次预览。
- 切换目标或执行撤销时播放停止，复位后可以立即编辑变换。销毁视口后帧调度已清理。GLB 未加载或目标丢失时，用户仍可看到已保存的配置。

首版范围限于选中节点的编辑器预览。多节点编排、时间轴、触发器、展示端自动播放、其他动效类型和自定义旋转轴心留待有具体需求时再规划。
