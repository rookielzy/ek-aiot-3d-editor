# Domain Docs

本仓库采用 single-context 布局。
core、React、Vue 和示例共享根目录的领域术语与架构决策。

## 探索前读取

- 根目录 `CONTEXT.md`：读取领域概念和术语。
- 根目录 `docs/adr/`：读取与当前工作相关的架构决策。

文件或目录不存在时，直接继续工作，无需报告缺失或建议预先创建。
由 `/domain-modeling` 在实际确定术语或决策时按需创建。

## 文件布局

- `CONTEXT.md`：整个仓库共享的领域上下文。
- `docs/adr/`：整个仓库共享的架构决策记录。

## 使用领域词汇

任务标题、重构建议、假设和测试名称涉及领域概念时，
使用 `CONTEXT.md` 定义的词汇，遵守其中的同义词约定。

所需概念尚未收录时，先判断是否引入了项目不使用的术语；
若确为领域文档缺口，记录下来供 `/domain-modeling` 处理。

## 显式指出决策冲突

建议或实现与已有 ADR 冲突时，明确指出对应 ADR、
冲突内容，以及值得重新讨论该决策的理由。
