# React Inspector 表单体验改进

grill-with-docs 的三轮设计选择和完整共同理解已由用户确认，React 实现已开始。Vue 实现须等待用户验收 React。

## 已确认

- 先完成并验证 React shell，再处理 Vue shell。
- 优先顺序：输入与提交体验、选择与错误反馈、视觉统一。
- React 首期覆盖 Inspector 的变换、材质、灯光、相机和环境表单；先完成 Transform 切片验证，再扩展其他表单。
- 保留当前 Workbench 布局、配色和紧凑信息密度，以 shadcn 统一控件、焦点状态、间距和提示。
- 数值输入过程中保留草稿，Enter 或失焦提交，Escape 恢复当前已提交值；无效输入保留草稿并显示字段错误，不修改场景。有效且实际改变值的提交产生一个撤销步骤，Enter 后失焦不重复提交。
- 普通枚举采用支持键盘操作的 Select，资产选择采用可搜索选择器并提供“无”选项；选中立即提交，关闭或 Escape 不修改值，关闭后焦点回到触发控件。保留禁用原因与错误提示。
- shadcn 组件源码放在 packages/react 内部，由 React 包编译并发布所需 CSS，使用者沿用现有样式导入方式，无需额外配置 Tailwind。样式限定在编辑器与其弹出菜单范围内，避免影响宿主页面。
- 切换对象或材质编辑目标时，丢弃尚未提交的草稿与错误提示；目标切换优先于失焦提交，旧目标草稿不得写入新目标。普通 Tab 切换字段按失焦规则提交。
- 撤销/重做、场景恢复或外部更新改变正在编辑的字段时，以最新场景值为准；取消对应草稿并清除过时的字段错误。其他字段更新不应打断当前输入。
- 颜色控件提供预览块、颜色选择器与十六进制输入；弹层内调整草稿，点击“应用”后更新场景。Escape 或点击外部关闭取消；有效且实际改变值的一次应用产生一个撤销步骤。首期仅在控件内预览颜色。
- 文本采用 Enter/失焦提交、Escape 取消及字段错误提示；中文输入法选词期间的 Enter 不触发提交。开关切换立即提交。
- 数值首期保留键入、步进和键盘操作；拖拽标签调值、额外滑杆、场景实时颜色预览和连续调色的撤销合并不在首期范围内。

## 实现约束

- 保留现有 Core 命令、校验、历史与版本化 SceneSnapshot 契约；表单草稿与弹层状态属于 React 临时状态，不进入持久快照。
- 资产清空选项遵守 Core 字段的可清空约束，不能让“无”选项绕过领域校验。
- 保持现有公开组件使用方式与 styles.css 导入方式；验证源码开发和发布构建两种使用路径。
- 组件具体依赖、内部组织和构建配置在实现中依据官方文档与仓库实际情况选择，满足上述交互和发布边界。

## 验收条件

- 通过 pnpm build、pnpm typecheck、pnpm test、pnpm test:browser；另构建 React proof-loop 示例，验证其类型检查与生产构建。
- 验证导入资产、选择对象、变换、撤销/重做、序列化与恢复的完整 proof loop。
- 覆盖输入提交与取消、无效草稿、中文输入法 Enter、目标切换、历史及外部值更新、焦点保持、不重复产生撤销步骤。
- 验证普通 Select 和资产搜索的键盘操作、关闭取消、焦点恢复、禁用原因、错误提示及合法清空行为。
- 验证颜色草稿应用与取消，以及一次有效应用的撤销粒度。
- 浏览器验证窄面板、滚动、深色主题中的弹层样式与裁剪；验证宿主页面样式隔离、发布 CSS 直接使用以及中英文提示完整。
- 交付可运行的 React demo 和前后截图供用户体验；用户验收 React 后，才开始 Vue 实现。

## 实现与验证结果

- React Inspector 已接入内部适配的 shadcn/ui Input、Button、Select、Popover、Switch 和 Command 控件，以及 Radix/cmdk 依赖。
- 统一了数值与文本草稿、取消、中文输入法、字段错误、目标切换和提交失败反馈；资产可搜索，颜色草稿通过“应用”一次提交。
- 保留显式默认值创建材质 override 的语义，已保存的相同值不重复产生撤销步骤。
- Tailwind 工具类使用 ek 前缀，不引入 preflight；弹层通过 portal 避免面板裁剪，复制当前编辑器的主题变量。
- pnpm build、pnpm typecheck、React proof-loop 的生产构建与类型检查均通过。
- 常规回归：116 个测试文件、971 项测试通过。Windows/Node 验证环境采用 NODE_OPTIONS=--no-experimental-webstorage，Vitest --pool=forks --maxWorkers=2 --testTimeout=60000；依赖安装与 pnpm 构建使用仓库固定的 pnpm 9.15.9，已有 shell 脚本通过 Git Bash 执行。
- 浏览器完整回归：15 个测试项目文件、105 项测试通过，涵盖三种 Chromium 尺寸。使用 RAYON_NUM_THREADS=4 限制预构建资源占用，Vitest --config vitest.browser.config.ts --testTimeout=60000；浏览器 API 显式绑定 127.0.0.1。
- 修复了浏览器 fixture 未提供资产名称及恢复测试受已保存语言影响的问题；失败的 9 个案例先专项复跑通过，再完整回归通过。
- 发布产物独立检查通过：加载 dist/index.js 与 dist/index.css 可编辑字段；宿主按钮样式不被重置，深色弹层继承主题，Escape 和外部点击取消颜色草稿不改变场景。
- git diff --check 通过；Core 与 Vue 源码未修改。React README、第三方许可和 patch changeset 已补齐。
