# 01：持续自转闭环

**What to build:** 在 React 和 Vue 默认工作台中，从画布或层级树选中一个模型节点或可独立变换的 GLB 子节点，在右侧「对象 → 动效」添加持续自转。用户可以修改或移除配置、手动预览、停止后继续编辑，并在重新打开项目后再次预览。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## 验收条件

- [ ] 单选支持的节点时显示「动效」页签，并跟随当前选中节点。目标暂未加载或 GLB 子节点无法解析时，保留已保存的配置并解释预览不可用的原因。React 和 Vue 使用同一套字段含义、校验规则以及中英文文案。
- [ ] 每个节点可保存一项配置。新增自转默认使用节点局部 Y 轴和 +90°/秒。用户可选 X / Y / Z 轴，转速须为有限的非零值，正负表示方向。无效输入保留已提交的配置，新增、修改和移除支持撤销和重做。
- [ ] 手动预览一个选中节点的已提交配置。风扇 GLB 叶片以 +90°/秒绕自己的局部 Y 轴旋转，一秒转过 90°，四秒转一圈，外壳保持原位。GLB 子节点以模型的原始局部姿态作为起点，有变换覆盖时采用覆盖后的姿态。
- [ ] 预览期间锁定目标的动效参数和变换编辑，仍可改变视角或切换选中节点。停止、切换目标、离开页签或重新投影场景时，退出预览并恢复基础姿态。再次预览从起点开始，关闭视口时清理播放调度，停止后恢复按需绘制。
- [ ] 参数保存在版本化 Snapshot 中。旧项目打开后动效为空，复制节点时携带独立配置，删除节点时一并移除配置。预览的开始、逐帧播放和停止均保留原 Snapshot 和历史栈。预览期间导出仍保存基础姿态与已提交参数，重新打开项目后可以再次手动预览。
- [ ] 通过正常 Editor 命令、runtime 帧调度和 React/Vue 工作台入口验证上述闭环，覆盖旧项目加载、项目导出和重新加载。
