# 02：往返移动闭环

**What to build:** 在 React 和 Vue 工作台的「对象 → 动效」增加往返移动。用户选中单个模型节点或可独立变换的 GLB 子节点后，可以设置相对于基础姿态的位移、手动预览往返、停止复位，并保存配置以便重新打开项目后再次预览。

**Blocked by:** 01（持续自转闭环提供节点动效配置与独立预览）

**Status:** ready-for-agent

## 验收条件

- [ ] 两端面板的往返移动字段一致，包括父级 X / Y / Z 轴、带方向的位移和单程时长。默认值为父级 X 轴、+1 场景单位、单程 2 秒。位移可为正或负且非零，时长为正数，所有数值为有限值。
- [ ] 滑台从基础位置出发，按固定缓入缓出曲线移动，第 2 秒到达 +1 的终点，第 4 秒回到起点并继续循环。旋转父级后仍沿父级 X 轴移动，带负号的位移朝该轴的反方向移动。
- [ ] 往返移动沿用手动预览、编辑锁定与退出复位行为。播放时可移动视角。停止、切换节点或离开页签后恢复基础位置，再次预览从起点开始。播放中的位置留在运行态。
- [ ] 同一节点在持续自转和往返移动之间切换时，使用新类型的默认参数。切换产生一次可撤销编辑，撤销可恢复原类型和参数。保存并重新打开项目后，往返移动配置和基础姿态均可恢复。
- [ ] 通过正常 Editor 命令、runtime 帧调度和 React/Vue 工作台入口验证往返周期、父级坐标和保存恢复。持续自转的配置、播放与复位仍通过验收。
