# 工作台 shadcn UI 改造规格

Status: ready-for-agent
日期：2026-11-10
范围：用户已确认三轮设计选择、验收边界及 13 项任务拆分。本轮完成规划发布；产品实现尚未开始。

## Problem Statement

Inspector 已采用内部 shadcn 风格控件，而其余工作台模块仍主要使用原生控件、自定义样式和各自维护的弹层逻辑。用户在项目菜单、场景树、资源维护和数据配置之间切换时，控件、焦点及反馈体验不够一致。已有工作台能力完整，本次需要在保留它们的前提下提升操作连续性和可发现性。

## Solution

保留现有浅色、紧凑桌面工作台的主要布局和配色，将统一的控件与交互规范扩展到非 Inspector 模块。按高频操作、资源维护、数据配置、整体收尾推进。先完成 React 并由用户体验验收，再在 Vue 中实现等价行为；每个切片同时交付可操作界面和对应验证。

## User Stories

1. 作为编辑者，我希望直接访问撤销、重做和移动/旋转/缩放，以便快速完成高频编辑。
2. 作为编辑者，我希望按职责查找相机、辅助显示和节点命令，以便在紧凑界面中发现功能。
3. 作为编辑者，我希望清楚区分当前工具、开关状态和禁用原因，以便知道操作是否可用。
4. 作为键盘用户，我希望菜单可以可靠打开、操作和退出，以便不用鼠标也能执行命令。
5. 作为编辑者，我希望一次性命令执行后收起菜单，而辅助显示切换时保留菜单，以便连续调整。
6. 作为项目使用者，我希望继续打开及完整或部分导出项目，以便保留当前保存和恢复语义。
7. 作为场景编辑者，我希望用方向键浏览和展开场景树、用 Enter 选择，以便快速定位对象。
8. 作为场景编辑者，我希望键盘焦点与实际选择清晰区分，以便浏览时不误改当前编辑目标。
9. 作为场景编辑者，我希望继续搜索、多选和双击聚焦节点，以便保留原有编辑效率。
10. 作为场景编辑者，我希望通过节点的明确更多入口操作对象，以便不依赖隐藏手势。
11. 作为资源使用者，我希望看到资源名称、类型和状态摘要并展开详情，以便在窄侧栏中判断情况。
12. 作为资源使用者，我希望继续搜索、过滤和排序，以便找到需要使用或修复的资源。
13. 作为资源使用者，我希望批量导入时看到每项结果，以便区分成功与失败。
14. 作为资源使用者，我希望在资源附近看到替换、恢复和重导入反馈，以便确认维护结果。
15. 作为项目使用者，我希望持续看到重要问题并进入修复路径，以便不遗漏短暂出现的错误。
16. 作为编辑者，我希望问题抽屉打开时仍可操作场景，以便边查看问题边修复。
17. 作为编辑者，我希望从问题跳转至既有能力支持的目标，以便缩短定位过程。
18. 作为数据配置者，我希望连接、查询和测试结果分区组织，以便理解长表单。
19. 作为数据配置者，我希望错误尽量出现在对应字段附近，以便准确修正配置。
20. 作为数据配置者，我希望保留显式保存和测试操作，以便控制何时应用完整配置。
21. 作为数据配置者，我希望离开未保存编辑时选择继续或放弃，以便保护草稿。
22. 作为绑定配置者，我希望在足够宽的对话框中编辑对象绑定，以便处理较长配置。
23. 作为键盘用户，我希望 Escape 只处理最上层弹层并获得正确焦点，以便连续操作。
24. 作为中文用户，我希望输入法及文本编辑不触发场景快捷键，以便正常输入。
25. 作为桌面用户，我希望不同窗口尺寸、窄侧栏及长名称下的控件仍可达，以便持续编辑。
26. 作为双语用户，我希望切换语言后所有新增提示一致且编辑状态保留，以便不中断工作。
27. 作为宿主开发者，我希望继续使用现有扩展区域和样式入口，以便升级无需重新配置集成。
28. 作为宿主开发者，我希望编辑器及弹层样式不影响宿主，以便组件可嵌入现有应用。
29. 作为项目使用者，我希望 UI 状态不会进入 Scene Snapshot，以便项目继续可靠序列化和恢复。
30. 作为 Vue 用户，我希望获得经 React 验收的等价体验，以便两个框架的工作流程一致。

## Implementation Decisions

1. **范围和顺序**：覆盖项目菜单、视口工具、场景树、资源、项目状态、问题抽屉、数据源、查询、对象绑定及外壳一致性。优先高频操作，然后资源维护，再数据配置，最后整体收尾。React 验收通过后才开始 Vue。
2. **视觉和发布边界**：沿用当前主要布局、浅色配色和紧凑密度，允许调整模块内分组与弹窗。复用并按需扩充包内 shadcn 风格组件；React/Vue 使用适合各自框架的实现。宿主继续导入包发布的样式，无需配置 Tailwind。编辑器及 portal 弹层样式隔离，保留已有主题继承，不新增主题系统。
3. **基础组件交付**：随首个真实工作流引入所需原语，不先建设独立设计系统包。实施时依据实际安装版本查阅官方文档确定具体组件和键盘细节；不将特定组件名称当作产品行为的替代。
4. **高频工具**：撤销/重做、移动/旋转/缩放保留直接入口。辅助显示、相机及较低频节点操作进入分组菜单。统一可见焦点、选中状态、可用快捷键提示及禁用原因。一次性命令执行后关闭菜单，连续辅助显示切换保持菜单打开。现有吸附、框选、相机及节点命令全部可达。
5. **项目操作**：保留打开、完整导出及显式部分导出、处理中反馈和失败详情；继续使用既有 readiness 和 capability 判断。
6. **场景树**：上下键在可见节点间移动焦点，左右键展开/折叠，Enter 执行选择；焦点与 selection 分离，浏览焦点不自动更新 Inspector。保留多选修饰键、搜索及其祖先展示、选中祖先自动展开、双击聚焦。更多入口消费既有节点命令与能力判断；覆盖对象、分组、灯光、相机及 imported target，不简化为示例模型列表。
7. **资源**：列表摘要突出名称、类型、状态，详情可展开。保留搜索、类型/状态筛选、排序、批量选择/拖入、栅格用途、逐项导入结果、替换、缺失载荷恢复及 GLB reimport/remap 诊断。反馈留在对应资源或队列项附近，不将部分成功显示为全部成功。
8. **问题与状态**：状态栏提供摘要，问题区域提供持续可见的详情及已有能力支持的定位/恢复。抽屉保持非模态，不阻止场景编辑；关闭抽屉不清除问题。保留来源、严重性、目标和实际恢复结果。
9. **数据配置**：分区组织连接、查询编辑和测试结果。保留既有显式保存、测试、校验和放弃草稿边界；字段错误就近呈现，整体错误仍有可见出口。较长编辑流程提供足够空间的对话框，不能改成 Inspector 式逐字段失焦提交。查询、映射、参数、凭证和预览继续遵循现有数据源契约。
10. **对象绑定**：保留现有绑定编辑、保存、删除、对象切换和定位能力，长表单使用对话框；未保存修改离开时明确提供继续编辑/放弃修改。取消确认继续保留草稿。
11. **焦点和快捷键**：Escape 优先关闭最上层弹层；有草稿时遵循确认流程。取消后回到触发入口，执行定位后进入目标区域。输入期间不执行场景快捷键，中文输入法选词不被误作提交。弹层内触发次级确认时，逐层处理焦点而非同时关闭所有界面。
12. **外壳和宿主兼容**：统一导航、标题、页签、滚动和收放控件；保留左右面板收放及鼠标/键盘调宽、宿主 render props/scoped slots 和既有语言 API。切换面板或语言不重建 editor/runtime。
13. **数据边界**：沿用 Core 命令、校验、历史和版本化 Scene Snapshot。UI 草稿、搜索、弹层和焦点属于临时状态；Three.js 对象、File、Blob、object URL、纹理、PMREM 和 resolver 结果不进入持久快照。运行时失败仍呈现为问题。
14. **交付门槛**：React 功能、回归、可运行示例及截图准备完成后请求用户体验验收；技术检查通过不能代替用户验收。Vue 首项明确受此门槛阻塞。

## Testing Decisions

- 以真实 EditorWorkbench 宿主的可见操作为主要边界，复用已有适配器 DOM 行为、浏览器工作台和 proof-loop 测试。断言用户观察到的结果，不锁定内部原语、CSS 类或实现结构；不为本次 UI 改造新增 Core 测试接口。
- 每项实现同步验证对应行为：树焦点与选择、菜单开闭、禁用原因、草稿保护、中文输入、导入部分失败、问题修复、数据保存/测试/绑定。既有测试覆盖保持有效，不重复建立等价测试。
- 完整回归导入、选择、变换、撤销/重做、导出与恢复；保留 Inspector 提交、取消和历史语义。
- 浏览器验收尺寸为 1440×900、1920×1080、1100×800，覆盖窄侧栏、长名称、滚动、空状态和错误状态；检查弹层裁剪、焦点与快捷键。
- 检查中英文、宿主扩展区、发布产物的样式隔离和弹层主题继承。分别提供 React/Vue 可运行示例与关键状态截图。
- 实施前读取适用测试技能，按当前仓库配置执行构建、类型检查、适配器常规/浏览器测试和示例构建。测试从包目录调用，避免从仓库根目录运行测试；不直接调用 tsc。
- 仓库当前未提供上层指引提及的 bun run check；现有脚本使用 pnpm。实施时复核脚本并记录实际验证命令、结果和限制，不为满足不存在的命令增加无关工具链迁移，也不宣称未运行检查已通过。

## Out of Scope

整体布局重设计；新增暗色主题系统；移动端适配；场景树拖拽重排或新增重命名能力；新的核心编辑命令、数据源能力或 durable schema；独立通用设计系统包；Inspector 的再次重写；跨会话布局持久化；发布 npm、合并或部署。本次交付为规划文档，尚未开始产品实现。
