## Acceptance criteria

- [ ] 连接、查询编辑与测试结果分区清晰；较长编辑流程在足够空间的对话框完成。
- [ ] 保留既有参数、映射、凭证、校验和预览契约；统一输入、选择、按钮和反馈。
- [ ] 字段错误就近显示，整体错误可见；测试的处理中、成功、失败及现有结果保持真实。
- [ ] 显式保存/测试语义保留，失焦不会将整个表单改为逐字段提交。
- [ ] 离开未保存修改时提供继续编辑/放弃；继续编辑保留草稿，Escape 按最上层处理。
- [ ] 输入法、焦点恢复及中英文有效；通过真实工作台验证保存、测试、无效输入和草稿保护。

## Validation
