## What to build

在足够宽的对话框中完成对象绑定编辑、保存及定位，并保护未保存修改。

## Acceptance criteria

- [ ] 保留既有绑定字段、保存、删除、对象选择及定位行为；错误与反馈清晰。
- [ ] 长表单可滚动且操作入口可达，统一控件与数据配置视觉。
- [ ] 切换对象、关闭或定位等离开操作按现有草稿边界确认；继续编辑保留内容，放弃后执行原意图。
- [ ] 次级确认与父对话框逐层处理 Escape 和焦点；取消回入口，定位进入目标区域。
- [ ] 保存后的预览、项目恢复和 Inspector 关联行为保持现有契约。
- [ ] 验证编辑→保存→定位，以及未保存切换/关闭、取消确认、明确放弃的真实路径。

## Validation

复用真实工作台的既有适配器行为与浏览器测试；通过可见控件操作并断言用户结果。按规格执行本切片适用的验证，记录实际命令、结果与未完成项；涉及测试修改时先读取仓库适用测试技能。保留 Core/Scene Snapshot 和既有 Inspector 语义，UI 临时状态不进入持久快照。
