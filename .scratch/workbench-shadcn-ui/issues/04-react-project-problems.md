## Acceptance criteria

- [ ] 状态栏保留真实项目/资源/运行时摘要；重要错误持续可见，关闭抽屉不清除问题。

- [ ] 来源、严重性、目标、详情及已有定位/恢复操作可见；恢复进度和结果与真实操作一致。
- [ ] 取消返回入口，定位进入目标区域；只提供当前能力支持的目标操作。
- [ ] 完整/部分项目导出及恢复诊断保留，修复后摘要和问题详情正确更新。
- [ ] 验证发现问题→定位或恢复→结果反馈路径；当前已有数据目标定位回归，跨模块最终回归在 07 完成。
