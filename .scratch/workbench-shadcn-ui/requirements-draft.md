# 工作台 shadcn UI 改造：需求草稿

当前阶段：三轮设计及任务拆分已于 2026-11-10 全部确认，正式规划已发布；产品实现尚未开始。本文件保留讨论记录，执行以 [正式规格](spec.md) 和 [任务索引](README.md) 为准。

## 已确认（2026-11-10，第一轮）

- 规划覆盖 React 和 Vue。先完成并验收 React，再由 Vue 对齐交互标准。
- 保留当前工作台主要布局、配色和紧凑密度；允许调整模块内部信息分组、菜单及弹窗流程。
- 本期不包含整体布局重设计、暗色主题系统或移动端适配。
- 优先顺序：
  1. 项目菜单、工具栏、视口工具、场景树。
  2. 资源面板、项目状态、问题修复流程。
  3. 数据源、查询测试、对象绑定。
  4. 全局视觉、键盘及焦点规则的统一验收。

## 已核实的代码基线

- React/Vue 的内部 ui 组件主要由 Inspector 表单消费；Workbench 和 Data 系列仍使用原生控件、自定义 CSS 与手写弹层。
- 场景树已有搜索、多选修饰键、双击聚焦和选中祖先自动展开；目前使用递归列表与按钮，完整树键盘导航需要独立设计。
- 项目及视口工具已有关闭与焦点处理，改造需保留并统一这些行为。
- 资源已有搜索、筛选、排序、批量导入队列、替换、缺失恢复和 GLB reimport/remap。
- 数据绑定已有草稿及放弃修改确认；不能套用 Inspector 的逐字段提交规则覆盖整个编辑事务。
- 问题抽屉当前为非模态区域；是否保持非模态应明确记录。

## 既有约束与参考

- 延续 [组件与样式发布边界](../../docs/adr/0001-react-inspector-ui-style-boundary.md)：包内提供组件与样式，宿主无需配置 Tailwind，样式作用域覆盖编辑器及弹层。
- 保留 Core 命令、历史及版本化 Scene Snapshot 契约；UI 临时状态和运行时值不进入持久快照。
- 参考 [桌面工作台规格](../desktop-workbench-refresh/spec.md) 与 [Inspector 表单规格](../react-inspector-forms/spec.md)，已有能力作为保留与回归条件。

## 已确认（2026-11-10，第二轮）

- 保留撤销/重做、移动/旋转/缩放等高频直接入口；辅助显示、相机和较低频节点操作进入分组菜单。统一选中状态、快捷键提示与禁用原因。一次性命令执行后关闭菜单，连续辅助显示切换保持菜单打开。
- 场景树纳入键盘导航：上下移动焦点、左右展开/折叠、Enter 选择；焦点与选中分离。保留现有多选修饰键、搜索、双击聚焦，节点操作提供明确的更多入口。不增加拖拽重排或新的重命名能力。
- 资源以列表摘要和展开详情组织，突出名称、类型和状态；导入失败、替换和恢复反馈保留在对应项目附近。
- 问题抽屉保持非模态，允许同时操作场景。提供既有能力支持的定位和恢复入口，重要错误持续可见，不仅通过短暂通知呈现。
- 数据配置保留现有显式保存、测试和放弃草稿边界；连接配置、查询编辑、测试结果及对象绑定分区组织，字段错误尽量就近显示。较长编辑流程使用有足够空间的对话框，不将 Inspector 逐字段失焦提交规则套用到数据配置。
- Escape 优先关闭最上层弹层；取消后焦点返回入口，执行定位后进入目标区域；文本输入及中文输入法不触发场景快捷键。未保存草稿保留继续编辑/放弃修改的明确选择。

## 已确认的最终验收边界（2026-11-10，第三轮）

- 使用真实 EditorWorkbench 宿主的可见操作作为主要测试边界，复用现有适配器行为与浏览器测试；只针对当前改动补充覆盖，不为 UI 重写新增 Core 测试接口。
- 回归导入、选择、变换、撤销/重做、导出及恢复；数据配置覆盖保存、测试、绑定和草稿保护；覆盖树键盘导航、弹层焦点、中文输入法、禁用反馈和问题修复路径。
- 沿用 1440×900、1920×1080、1100×800 桌面验收尺寸，检查窄侧栏、滚动、长名称、空状态及错误状态。
- 检查中英文、宿主扩展区、发布产物样式隔离及既有 Inspector 回归。React 交付可运行示例、前后与关键状态截图、验证结果，用户验收后才能进入 Vue。
- 本轮交付规格与独立任务，不修改产品代码；实施时依据安装版本查阅官方组件文档并选择原语。
- 仓库目前没有 bun run check 脚本，现有验证脚本为 pnpm build/typecheck/test/test:browser。实施时记录此差异，不将不存在的命令标记为通过；测试从对应包目录调用，并遵守相关测试技能要求。
