# 14 时间轴动作编排

**What to build:** 在已有时间轴上安排节点动效、GLB 动画片段和相机切换，使用户能够编排、预览并触发完整的多对象演示。

**Blocked by:** [08 GLB 动画片段](08-glb-animation-clips.md)、[10 扫光与流向指示](10-scan-light-and-flow.md)、[12 相机切换](12-camera-transitions.md)、[13 属性关键帧](13-property-keyframes.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 同一条时间轴可安排已配置的播放型动效、GLB 片段和相机切换，并调整各动作的时间位置。
- [ ] 用「切镜头 → 开门 → 传送带运行」验证按顺序播放。用带 GLB 片段的演示补充验证片段能在预定位置开始。
- [ ] 拖动播放头可检查上述演示的关键时刻。相互重叠的动作继续遵循同一套属性控制规则。
- [ ] 导出项目后在另一个框架宿主打开，时间轴及其动作引用恢复，展示模式可以触发整段演示。
