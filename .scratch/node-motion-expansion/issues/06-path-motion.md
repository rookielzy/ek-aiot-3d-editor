# 06 沿路径移动

**What to build:** 让用户配置对象路线、播放速度或时长、转向和进度，用于 AGV 巡航或实时定位。

**Blocked by:** [05 设备数据联动](05-device-data-motion.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 可配置一条含多个路径点的路线，并为对象设置起止进度、速度或时长。用含转弯的路线验证移动位置。
- [ ] 可以选择随路线转向。该设置打开时，AGV 经过转弯点后朝向路线方向。
- [ ] 路线可以播放，也可以根据实时字段定位。绑定进度 42% 时，AGV 到达路径对应位置。
- [ ] 编辑预览结束后恢复编辑状态。路径点、引用和设置随项目保存恢复，展示模式可再次播放。
