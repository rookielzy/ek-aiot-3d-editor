# 02 单程移动与播放设置

**What to build:** 让用户在现有面板配置一次性沿轴移动和适用的播放方式，并为节点动作配置场景加载或指定对象点击触发。

**Blocked by:** [01 点击开门](01-click-open-door.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 保存轴向、带方向的位移、时长与缓动后，气缸运动到配置的终点并保持。停止编辑预览后恢复基础位置。
- [ ] 适用的动作可配置单次、循环或往返，以及启动延迟和末帧行为。用同一个滑台验证单次到终点、循环从起点重播，以及往返返回起点。
- [ ] 可设置进入展示模式后自动启动，也可点指定对象启动另一节点动作。用场景按钮触发气缸验证触发目标和动作目标可分别选择。
- [ ] 设置可随项目保存恢复，在 React 与 Vue 上产生等价的播放和触发结果。
