# 01 点击开门

**What to build:** 在现有工作台为门或可独立选中的 GLB 门板配置定角旋转。用户可以在编辑器预览，并在重新打开项目后进入展示模式，点击门播放并保持打开。

**Blocked by:** 无

**Status:** ready-for-agent

## 验收条件

- [ ] 「对象 → 动效」可以设置旋转轴、目标角度、时长与缓动。对门板设为 90° 后，编辑预览按参数播放，停止后恢复编辑姿态。
- [ ] 配置可以撤销、重做并随 .ek3d 导出。重新打开项目后，展示模式读取同一配置。
- [ ] 在展示模式点击门，门转到 90° 后保持。拖动视角时不会误触开门。编辑控件在编辑模式可用。
- [ ] 退出展示模式后恢复编辑姿态，项目始终保存编辑态基础姿态。
- [ ] 通过实际工作台与视口验证操作，并确认同一份 .ek3d 可在 React 与 Vue 宿主打开并播放。已有持续自转、往返移动项目仍可打开和预览。
