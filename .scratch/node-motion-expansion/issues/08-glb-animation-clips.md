# 08 GLB 动画片段

**What to build:** 在工作台选择并预览 GLB 资源自带动画，在展示模式通过已保存的配置触发指定片段。

**Blocked by:** [03 多动效与材质过渡](03-parallel-motion-and-material.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 导入含多个动画片段的 GLB 后，可以识别并选择其中一个片段，预览其实际动作。
- [ ] 可配置倍速、单次或循环、适用的往返和循环次数，以及末帧保持。用叉车升降等片段验证实际表现。
- [ ] 片段涉及的属性遵循已确认的控制规则。退出预览后恢复编辑状态。
- [ ] 片段引用随项目保存恢复。资源更换后片段不可用时，显示可定位的问题并保留配置。
