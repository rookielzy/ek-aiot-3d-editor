# 03 多动效与材质过渡

**What to build:** 让编辑者为同一节点配置多条动效，并用颜色、高亮和透明度变化展示设备状态。播放时不同属性可以同时变化，演示动作可在同一属性上接续。

**Blocked by:** [02 单程移动与播放设置](02-one-way-motion-and-playback.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 可以独立添加、编辑、删除和预览同一节点的动效。每次编辑可以撤销、重做，保存并重新打开后保留各条配置。
- [ ] 编辑者可为适用对象设置目标颜色、高亮或不透明度，以及过渡时长和缓动。退出编辑预览后恢复编辑态材质。
- [ ] 风扇叶片在自转时可同时变色。另一节点的独立动效也可以同时播放。
- [ ] 门刚开始打开时触发关门，门从当时的角度回转，到达关门终点。展示只体现接管后的旋转动作。
- [ ] 用 React 和 Vue 打开含多动效的同一项目并验证播放，也验证旧项目的单条动效仍具有原有预览行为。
