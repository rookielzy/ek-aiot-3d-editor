# 13 属性关键帧

**What to build:** 提供多对象时间轴。用户可以为位置、旋转、缩放、颜色和透明度设关键帧，并拖动播放头查看指定时刻。

**Blocked by:** [03 多动效与材质过渡](03-parallel-motion-and-material.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 可在同一时间轴添加多个节点的属性轨道，增改删位置、旋转、缩放、颜色和透明度的关键帧。
- [ ] 拖动播放头可看到关键帧时刻及两帧之间的属性值。同一时刻重复定位得到一致结果。
- [ ] 时间轴遵循已确认的属性控制规则。编辑预览结束后恢复编辑状态。
- [ ] 关键帧可以撤销、重做，并在项目保存和重新打开后恢复。
