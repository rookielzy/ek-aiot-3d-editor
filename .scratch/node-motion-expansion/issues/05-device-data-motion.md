# 05 设备数据联动

**What to build:** 在已有数据源与对象绑定的基础上，可用设备字段条件触发动作，也可把实时读数映射到节点属性。

**Blocked by:** [03 多动效与材质过渡](03-parallel-motion-and-material.md)

**Status:** ready-for-agent

## 验收条件

- [ ] 编辑者可配置来源字段、比较条件和目标动效。温度从阈值以下升到阈值以上时，可以启动告警动效。
- [ ] 实时映射可配置输入和输出范围。把 0–100% 映射到 0–90° 时，阀门读数 42% 对应 37.8°，读数变化后姿态随之更新。
- [ ] 阀门角度绑定实时数据时，演示触发不会覆盖该属性。其他属性可继续播放动效。
- [ ] 保存并重新打开项目后仍可使用设备字段配置，按现有宿主数据连接流程恢复读数。字段缺失时可定位配置问题。
- [ ] 通过真实数据夹具观察数据到达后的展示结果，覆盖阈值触发、读数更新和属性控制权。
